# Game storage template

This folder drafts the storage structure described in [design.md](../design.md). It is not a playable game. Names, IDs,
a two-coordinate grid, and metadata tables are illustrative choices.

Start with [game.md](game.md), [state.md](state.md), and [world.md](world.md). One sample cell references one object,
one actor, and the player. [step0001.md](steps/step0001.md) is an empty turn template, not a completed turn.

Replace `{{...}}` placeholders when creating actual content. Duplicate entity pages with unique IDs and update their
relative links. Keep each page's current content and bottom changelog in sync. Replace media path placeholders with
relative links when files exist; see [media guidance](media/README.md).
